LECTURA EXPLÍCITA CON JINA

Revisar una página web

Al pulsar «Enviar URL a Jina», el servicio externo recibirá esta dirección y obtendrá su contenido. Ni tu pregunta ni tu historial se envían a Jina. El texto extraído no se usará en el chat hasta que lo revises y lo añadas.

BÚSQUEDA WEB EXPLÍCITA

Buscar en la web

Al buscar, Jina Search recibirá exactamente esta consulta y podrá asociarla con tu dirección IP o API key. No se envían la pregunta del chat ni el historial. Los resultados son solo una vista previa; la URL elegida se enviará después a Jina Reader para que revises el texto antes de usarlo. Esta función requiere configurar JINA_API_KEY en el servidor local.
